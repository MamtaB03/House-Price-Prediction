This project presents an end-to-end Supervised Machine Learning pipeline developed to predict real estate valuation based on key physical and locational property features. Real estate pricing is inherently dynamic and influenced by several continuous and categorical attributes, making it an ideal candidate for predictive modeling and automated analytical assessment. The technical architecture encompasses everything from raw data cleaning and exploratory analysis to multi-model training and interactive web deployment.

The execution begins with data preprocessing using the Pandas library. Raw synthetic dataset records containing simulated real-world anomalies—such as missing feature values and price extreme outliers—are cleaned systematically. Missing numerical entries like square footage area are filled using median imputation to prevent distributional skewness, while discrete features like bathroom counts are imputed using the mode. To eliminate skewed outliers that could degrade model training, the Interquartile Range (IQR) method is applied to filter the target price distribution. Following preprocessing, Exploratory Data Analysis (EDA) is performed using Matplotlib and Seaborn to generate descriptive visualizations. These charts illustrate price distributions, bedroom count variance, feature-to-target scatter trends, and a complete correlation heatmap, confirming strong positive linear relationships between square footage and property price alongside negative correlations with property age.

For predictive modeling, four supervised regression algorithms of varying complexity were trained and evaluated: Linear Regression, Ridge Regression (utilizing L2 regularization), Decision Tree Regressor, and Random Forest Regressor. Evaluating these models against $R^2$ accuracy scores, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE) provides a comparative look at model generalization on unseen test data. Linear Regression serves as a simple yet highly effective model for this problem, offering both high accuracy and clear mathematical interpretability.

Finally, the best-performing model weights are serialized into a binary file (`.pkl`) via `joblib` and integrated into a Streamlit web interface. This frontend dashboard allows users to adjust inputs—such as area, bedroom count, house age, and location score—using interactive sliders and dropdowns to receive instant, formatted price predictions in Indian Rupees (₹). Overall, the project demonstrates a complete machine learning lifecycle, bridging raw data cleaning, comparative algorithm evaluation, and practical deployment.
